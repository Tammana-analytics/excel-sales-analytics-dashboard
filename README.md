# Excel Sales Analytics Dashboard

## Project Overview
This project analyzes sales data using Microsoft Excel to understand sales performance, product trends, and business insights.

## Tools Used
- Microsoft Excel 2013
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Dashboard Visualization
- Business Insights

## Project Work
- Organized and analyzed sales data.
- Used formulas to calculate sales.
- Performed sales checks to verify calculations.
- Created Pivot Tables to summarize sales data.
- Created Pivot Charts to visualize sales performance.
- Built an interactive-style dashboard to present key findings.
- Identified business insights to support better decision-making.

## Key Learnings
- Data analysis using Excel
- Data summarization and visualization
- Understanding sales trends
- Presenting business insights

## Conclusion
This project helped me practice Excel-based data analysis and dashboard creation as part of my Data Analyst learning journey.
